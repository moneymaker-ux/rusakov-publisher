Privacy Policy

Effective date: September 19, 2026

Rusakov Publisher (“the tool”, “we”) is an internal tool operated by Pavel Rusakov, an independent creator, to manage his own YouTube channel. This policy explains what information the tool accesses, how it is used, stored and shared, and how it can be deleted.

YouTube API Services

The tool uses YouTube API Services (the YouTube Data API and the YouTube Analytics API). By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses the tool

The only user is the channel owner, who signs in with his own Google account through Google OAuth 2.0. The tool is not offered to the public and has no sign-up.

Information the tool accesses

  • OAuth tokens issued by Google after the owner grants access.
  • Channel information: channel ID and title.
  • The channel's own videos: IDs, titles, descriptions, privacy status, scheduled publish time.
  • Statistics of the channel's own videos: views, likes, comment counts and YouTube Analytics reports (for example views and watch time).
  • Comments on the channel's own videos: comment text, the commenter's public display name and channel ID, and the time of the comment.

The tool does not access private data of any other YouTube user, does not use cookies or similar technologies, and does not show ads. This website does not use cookies or analytics.

How the information is used

  • To upload the owner's own videos and set their title, description, privacy status and publish time. Uploads happen only after the owner approves each video.
  • To show the owner how his videos perform, so he can plan new content.
  • To prepare reply drafts to comments on the owner's videos. A reply is posted only after the owner reviews and approves it.

The information is not sold, not used for advertising and not used to build profiles of commenters.

Where the information is stored and who it is shared with

  • OAuth tokens are stored only on the owner's computer, in a file readable only by the owner's user account. They are never shared.
  • Video information, statistics and comments are stored in the owner's private workspace in Notion (Notion Labs, Inc.), which only the owner can access.
  • Comment text is sent to Anthropic's Claude AI model to draft a reply. Only the comment and the video context are sent.

No other internal or external parties receive the information.

Retention and deletion

  • Information about the owner's own channel and videos is kept while the owner's authorization is active.
  • Comments written by other people are kept for no longer than 30 days, after which they are refreshed from YouTube or deleted.
  • If the owner revokes access, the tool revokes its token with Google and deletes all stored YouTube data within 7 days.

How to revoke access

In addition to the tool's own procedure for deleting stored data, access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions.

Security

Data is transferred over HTTPS. Tokens and API credentials are kept outside of source code and are never published.
